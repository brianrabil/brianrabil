vgpu wraps WebGPU in a small set of functions: `init` gets a device, `surface` binds a canvas, `effect` compiles a full-screen fragment shader, and `frameLoop` drives rendering. Shaders are written in WGSL, and uniforms are set by the variable names declared in the shader.

The background on this site is a vgpu effect. A full-screen effect is about 28 KB gzipped, and the package is safe to import from a client component in Next.js because it only touches browser APIs inside its functions.

## Things to know

- It is WebGPU only. There is no WebGL fallback, so plan a CSS or static fallback for browsers without WebGPU.
- `vgpu check file.wgsl --require-validation` validates WGSL with the same compiler the browser uses, which catches shader errors before deploy.
- Pause the frame loop when the canvas is off screen; vgpu leaves that to you.

## Try it

```ts
import { effect, frameLoop, init, surface } from "vgpu";

const gpu = await init();
const target = surface(gpu, canvas, { dpr: [1, 2] });
const fx = effect(gpu, wgslSource, { set: { params: { time: 0 } } });
frameLoop(gpu, (frame) => frame.pass(target, fx));
```
